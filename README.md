# DataDoctor

[![CI](https://github.com/mahdidaraeii/datadoctor/actions/workflows/ci.yml/badge.svg)](https://github.com/mahdidaraeii/datadoctor/actions/workflows/ci.yml)

A diagnostic workbench for tabular datasets. Give it a CSV and a target column
and it reports what is wrong with the data and whether it is safe to model.

Work in progress.
