# Sample datasets

Two small, real, clearly licensed datasets, bundled so `profile`, `quality` and `explore` can be
tried immediately after install. Both are regenerated by `scripts/make_sample_datasets.py`.

## `breast_cancer.csv` — classification

569 rows, 30 numeric features plus a `diagnosis` column (`malignant` or `benign`) as the target.
The features are measurements taken from digitized images of breast tissue samples: things like
the mean radius, texture and smoothness of the cell nuclei present.

Run: `uv run -m datadoctor explore data/sample/breast_cancer.csv --target diagnosis`

**Source:** Breast Cancer Wisconsin (Diagnostic), UCI Machine Learning Repository.
https://doi.org/10.24432/C5DW2B, loaded here through scikit-learn's bundled copy of it.

**License:** Creative Commons Attribution 4.0 International (CC BY 4.0). Sharing and adaptation
are permitted for any purpose, with credit given.

**Citation:** Wolberg, W., Mangasarian, O., Street, N., & Street, W. (1993). Breast Cancer
Wisconsin (Diagnostic) [Dataset]. UCI Machine Learning Repository.

## `wine_quality.csv` — regression

4,898 rows, 11 numeric physicochemical measurements (acidity, sugar, sulfur dioxide, pH, alcohol,
and so on) of white "vinho verde" wine samples, plus a `quality` column as the target.

`quality` is an integer score from 0 to 10 given by wine tasters, not a continuous measurement.
It is still a valid regression demonstration: the score is treated as a numeric target, and
because it only takes a handful of distinct whole-number values, `explore` draws its distribution
as a class-balance chart rather than a histogram, the same rule it applies to any discrete numeric
target such as a 0/1-coded classification label.

Run: `uv run -m datadoctor explore data/sample/wine_quality.csv --target quality`

**Source:** Wine Quality (white wine subset), UCI Machine Learning Repository.
https://archive.ics.uci.edu/dataset/186/wine+quality, downloaded directly since scikit-learn does
not bundle it.

**License:** Creative Commons Attribution 4.0 International (CC BY 4.0). Sharing and adaptation
are permitted for any purpose, with credit given.

**Citation:** Cortez, P., Cerdeira, A., Almeida, F., Matos, T., & Reis, J. (2009). Wine Quality
[Dataset]. UCI Machine Learning Repository.

## Regenerating

```
uv run --with scikit-learn python scripts/make_sample_datasets.py
```

Fetches both datasets fresh (breast cancer from scikit-learn's bundled copy, wine quality
directly from the UCI Machine Learning Repository) and overwrites the two files above.
scikit-learn is not a project dependency; it is only needed to run this script.
